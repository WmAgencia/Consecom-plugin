# Consecom Plugin v4.9.0 — Contexto

- Cofre Obsidian: conexão com um clique; mantém o selecionado e prioriza o cofre aberto. Continua limitado a `Consecom/Contexto`, sem acessar notas pessoais existentes.
- Claude Code, OpenCode e Codex: descoberta de CLIs em instalações padrão, executáveis nativos e pacotes npm do usuário; diferencia os arquivos de projeto da disponibilidade real do aplicativo.
- Busca limitada a nomes de pastas comuns no C: e D:, sem leitura de arquivos e sem execução de binários encontrados em repositórios.
- ChatGPT aparece primeiro; mostra estado do túnel e distingue disponibilidade do túnel de atividade MCP recente.
- Contexto: interface de três painéis com explorador de fontes/notas, busca, grafo, detalhes e ações de conexão.
- Nenhuma automação oculta do site ChatGPT nem cobrança separada de API é adicionada.

Importante: conectores CLI só são marcados como configurados após a ferramenta de instalação aceitar a operação. Um diretório chamado Claude Code não prova que o CLI está presente.
